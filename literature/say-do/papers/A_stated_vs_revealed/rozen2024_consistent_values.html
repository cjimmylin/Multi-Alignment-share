Rozen et al. (2024/2025) — Do LLMs Have Consistent Values?

  • Citation: Naama Rozen, Liat Bezalel, Gal Elidan, Amir Globerson, Ella Daniel. "Do LLMs Have Consistent Values?" ICLR 2025. arXiv:2407.12878 (v3, Oct 2024). The PDF header lists Bezalel first; arXiv metadata and the ICLR listing put Rozen first.
  • Venue: ICLR 2025 (poster; https://iclr.cc/virtual/2025/poster/30729).
  • URL: https://arxiv.org/abs/2407.12878
  • PDF downloaded: yes — rozen2024_consistent_values.pdf

Say–do construct

This is not a say–do study. It tests structural coherence of stated values: - whether LLM answers to Schwartz's PVQ-RR reproduce the human value hierarchy (ranking); - whether they reproduce the circumplex inter-value correlation structure (MDS). Coherence across items is treated as a precondition for "having" values.

Method and models

  • Models: GPT-4, Gemini Pro, Llama-3.1 8B/70B Instruct, Gemma-2 9B/27B. Temperatures 0 and 0.7.
  • Prompting strategies: basic; names (Aher et al.); persona descriptions; and a novel "Value Anchor" prompt that tells the model to answer as a person emphasising a given value.

Key quantitative findings

  • Value ranking: Spearman correlation with the human ranking is above 0.8 for many prompt–model combinations. The basic prompt with GPT is an exception, at very low correlation (Fig. 2a).
  • Same ends of the hierarchy: Benevolence is ranked high, e.g., 3rd and 1st for GPT-4 with the Value Anchor prompt at temperatures 0 and 0.7. Power Dominance is ranked low (19th).
  • Circumplex structure: Value Anchor MDS configurations fit the human structure best (Table 1).
  • Standard prompting does not give human-consistent inter-value correlations. Population-like coherence appears only under anchored or persona prompting.

Authors' explanation

  • Value coherence depends on how the model is prompted.
  • Anchoring induces coherent "value personas", similar to a population of humans.
  • Under standard prompting, a single consistent value system should not be assumed.

Limitations

  • Questionnaire-only. No behaviour.
  • Coherence is induced by the prompt, so it may reflect knowledge of human value structure rather than held values.

Relation to our finding

  • Background: stated value profiles of LLMs are prompt-constructed. This supports our design choice to assign the priority by instruction rather than rely on a model's "own" stated values.
  • No action channel, so no gap measurement.

Annotation

Rozen et al. administer the Schwartz PVQ-RR to six LLMs under several prompting strategies. Rankings and circumplex correlations match human data only under specific prompts, notably a "Value Anchor" persona prompt (Spearman ρ > 0.8 with human rankings). Standard prompting yields no human-like consistent value system. This ICLR 2025 paper shows that LLM "stated values" are largely prompt-dependent constructions, which is relevant to how say–do studies define "say".
