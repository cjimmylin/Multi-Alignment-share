Liu et al. (2025/2026) — Generative Value Conflicts Reveal LLM Priorities

  • Citation: Andy Liu, Kshitish Ghate, Mona Diab, Daniel Fried, Atoosa Kasirzadeh, Max Kleiman-Weiner. "Generative Value Conflicts Reveal LLM Priorities." ICLR 2026. arXiv:2509.25369 (v2).
  • Venue: ICLR 2026 (peer-reviewed).
  • URL: https://arxiv.org/abs/2509.25369
  • PDF downloaded: yes — liu2025_generative_value_conflicts.pdf

Say–do construct

The paper uses the ConflictScope pipeline. - Format-level "say": multiple-choice selection of an action in a generated value-conflict scenario. This is close to stating which value should win. - "Do": the model's free-text response to an LLM-simulated user in the open-ended version of the same scenario. A judge (GPT-4.1) decides which value the response supports. - Instruction-assigned priority: system prompts specifying a target value ranking test whether instruction moves behaviour.

Method and models

  • Value sets: HHH; Personal-Protective (from Huang et al.'s 2025 "values in the wild" taxonomy); ModelSpec.
  • Scenario generation: Claude 3.5 Sonnet, with filtering.
  • Ranking: values ranked with a Bradley-Terry-style analysis.
  • Target models: GPT-4o, GPT-4o-mini, Claude 3.5 Sonnet, Claude 3.5 Haiku, and two sizes each of Llama 3 and other open families.

Key quantitative findings

  • Protective values drop from 1st to near-last in open-ended use (Fig. 4).
  • In multiple-choice, models strongly prioritise protective values (harmlessness, responsibility, compliance, privacy): average rank 1.7.
  • In open-ended interaction, the average rank is 4.5. Models shift toward personal values (autonomy, authenticity, creativity, empowerment).
  • "All models except Claude show substantial shifts toward personal values when moving to open-ended evaluation."
  • Value orderings in the system prompt help moderately. Alignment with a target ranking improves by 14% overall. Prompts work better for HHH and Personal-Protective than for ModelSpec. Mahajan et al. report the per-set figures as about 23% for HHH vs about 4% for ModelSpec.

Authors' explanation

  • Values become apparent "under challenge" (Rokeach).
  • Multiple-choice formats elicit the normatively endorsed answer. Open-ended, user-facing interaction pulls toward accommodating the user (autonomy, helpfulness).
  • System prompting can "achieve moderate success".

Limitations

  • Simulated users. LLM judge.
  • The open-ended "action" is a chat response, not a tool action.
  • Some Claude models were unavailable for later experiments.

Relation to our finding

  • Very close analogue.
  • The MCQ→open-ended shift is a stated→enacted shift in the direction of the user-facing pressure, mirroring our compromise toward the competing pressure.
  • The system-prompt experiment is an instruction-assigned priority, as in our design. It helps only moderately (14%), consistent with our finding that a faithfully restated priority is still compromised in a sizeable minority of episodes.
  • Differences:
  • No agentic tool calls.
  • No separately judged reasons.
  • No condition that removes competing pressure.
  • No middle-plan coding.

Annotation

Liu et al.'s ConflictScope automatically generates value-conflict scenarios and compares models' multiple-choice choices with their open-ended responses to simulated users. In multiple-choice, models put protective values such as harmlessness first (average rank 1.7). In open-ended interaction they demote them (4.5) in favour of personal values like user autonomy. Explicit value orderings in the system prompt raise alignment to a target ranking by about 14%. An ICLR 2026 demonstration that stated priorities shift under realistic user pressure and that instruction only partly fixes this.
