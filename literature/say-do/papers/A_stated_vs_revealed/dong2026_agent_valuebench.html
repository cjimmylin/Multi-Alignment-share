Dong et al. (2026) — Agent-ValueBench: A Comprehensive Benchmark for Evaluating Agent Values

  • Citation: Haonan Dong, Qiguan Feng, Kehan Jiang, Haoran Ye, Xin Zhang, Guojie Song. "Agent-ValueBench: A Comprehensive Benchmark for Evaluating Agent Values." arXiv:2605.10365, May 2026 (Peking University).
  • Venue: preprint (not peer-reviewed at version read).
  • URL: https://arxiv.org/abs/2605.10365
  • PDF downloaded: yes — dong2026_agent_valuebench.pdf (12 MB)

Say–do construct

  • Text-only "LLM values": multiple-choice items following ValueBench-style protocols.
  • "Agent values": behaviour in executable agentic environments. Trajectory-level rubric judging is anchored by two "pole-aligned golden trajectories" per task.
  • Central claim: an agent's values diverge from those of its underlying LLM. Support comes from:
  • an intuitive argument;
  • an empirical comparison: dual-format identical items on four models and two value systems (Fig. 1; Appendix F.4);
  • a theorem (Theorem 1.1, "Agent–LLM Value Non-Identity").

Method and models

  • Benchmark: 394 executable environments, 16 domains, 4,335 value-conflict tasks, 28 value systems (332 dimensions). Each instance is curated by human psychologists.
  • Runs: 14 frontier models on 4 harnesses, more than 60,000 rollouts.
  • Validation: golden trajectories are discriminable by blinded psychologists (intended 4.61 vs cross 1.74 on 5-point scales). Pooled human–LLM value-track Spearman ρ = 0.982. Human–rubric agreement on 300 rollouts is 91.3% (Appendix I).

Key quantitative findings

  • "A shared 'brain' yields strikingly divergent value tendencies when transitioned from LLM to agentic modalities" (Fig. 1). This is shown graphically, without a single headline number.
  • "Value Tide": cross-model homogeneity in agent value profiles, with model-specific counter-currents. Example (MFT08): Loyalty crests at 8.01, above Care (6.35) and Fairness (6.11).
  • Harnesses bend profiles non-additively.
  • Steering: embedded skills steer agent values "more deeply and reliably" than prompt steering.

Authors' explanation

  • An agent transacts with an environment, receives consequential feedback and acts over long horizons.
  • The measurement channel (text vs trajectory) therefore induces a different "evidence law" over values.
  • Alignment levers shift toward harness and skill alignment.

Limitations

  • The LLM-vs-agent divergence evidence is mainly a figure on four models.
  • The benchmark is synthetic, though expert-curated.
  • An LLM-as-judge is used, even though validated.
  • Very new and not yet peer-reviewed.

Relation to our finding

  • The only benchmark found that makes the text-vs-agentic distinction central. It supports our premise that value expression in text does not carry over to agentic action.
  • Prompt steering is weaker than structural steering, which parallels our instruction-assigned priority being compromised under pressure.
  • Differences:
  • It compares the same items across formats. We compare the analysis and the action within one episode.
  • It does not judge reasons separately.
  • It does not manipulate removal of competing pressure.
  • It does not code compromise or middle plans.

Annotation

Agent-ValueBench provides 4,335 expert-curated value-conflict tasks in 394 executable environments and evaluates 14 frontier models on 4 agent harnesses (more than 60k trajectories) with validated trajectory-level rubrics. The authors argue empirically and formally that agent values diverge from the same model's text-only multiple-choice values. They find cross-model homogeneity ("Value Tide") that harnesses and embedded skills bend more than prompts do. The leading 2026 resource for value measurement in agentic, action-based settings.
