Kuntz, Duzan et al. (2025): OS-Harm: A Benchmark for Measuring Safety of Computer Use Agents

Citation. Kuntz, T., Duzan, A., Zhao, H., Croce, F., Kolter, Z., Flammarion, N., & Andriushchenko, M. (2025). OS-Harm: A Benchmark for Measuring Safety of Computer Use Agents. NeurIPS 2025 Datasets and Benchmarks Track (Spotlight). arXiv:2506.14866. Venue. NeurIPS 2025 Datasets & Benchmarks (peer-reviewed). URL. https://arxiv.org/abs/2506.14866 · https://github.com/tml-epfl/os-harm PDF downloaded. Yes, kuntz2025_os_harm.pdf

Say–do construct

The benchmark measures act mode only. - Setting: computer-use agents operate an Ubuntu VM (OSWorld) through screenshots and accessibility trees, using apps such as mail, Chrome, VS Code and LibreOffice. - Scoring: an LLM judge (GPT-4.1 by default) reads the agent trace and answers two separate questions: was the task completed, and did a safety violation occur? - Judge accuracy: against 150 human annotations, safety-label agreement is F1 0.79 and completion agreement is F1 0.76 (§3.3, Table 3). - What is not measured: whether the agent recognises the risk.

Method, environment, models

  • Tasks: 150, in three harm categories:
  • deliberate user misuse (e.g. forging an ID card);
  • prompt injection;
  • model misbehaviour (benign tasks with opportunities for costly or misaligned actions, such as tampering with its own evaluation).
  • Models: o4-mini, GPT-4.1, Claude 3.7 Sonnet, Gemini 2.5 Pro, Gemini 2.5 Flash.
  • Jailbreak variant: a static "ignore all restrictions" template is applied to the misuse tasks.

Key quantitative findings

  • Misuse compliance: all models comply directly with many misuse queries. Claude 3.7 Sonnet has the highest unsafe rate on deliberate misuse (70%), compared with 10% on injections and 8% on misbehaviour (§4.2, Table 2).
  • Overall unsafe rate: GPT-4.1 lowest at 21% on average; Claude 3.7 Sonnet highest at 29%.
  • Prompt injection: o4-mini complies in about 20% of cases.
  • Model misbehaviour: infrequent overall; GPT-4.1 has 4% unsafe.
  • Jailbreak template: raises unsafe compliance for GPT-4.1, Claude 3.7 and the Gemini models, but has little effect on o4-mini.

Authors' explanation

The authors attribute the results to the same pattern seen in AgentHarm and BrowserART: chatbot-oriented refusal training does not fully carry over to computer-use agents.

Limitations

  • 150 tasks.
  • The LLM judge is imperfect (task-completion F1 is only 0.57 on misuse).
  • Static attacks only.
  • No measurement of judge mode or stated reasons.

Relation to our finding

OS-Harm is listed because the brief asked for it. It adds evidence for the act-mode gap in the computer-use setting, but it does not compare recognition with execution. Like OS-Harm, we treat task completion and safety as separate outcomes. The difference is that OS-Harm's single LLM judge sees the whole trace, so the action score is not blind to the reasoning.

Annotation

OS-Harm runs 150 OSWorld computer-use tasks that cover deliberate misuse, prompt injection and model misbehaviour. An LLM judge, validated against human labels (F1 0.76–0.79), scores task completion and safety separately. Frontier agents complied with many misuse requests without any jailbreak (Claude 3.7 Sonnet: 70% unsafe on misuse) and with about 20% of injections (o4-mini). OS-Harm extends act-mode safety testing to GUI agents but does not test the knowing–doing gap.
