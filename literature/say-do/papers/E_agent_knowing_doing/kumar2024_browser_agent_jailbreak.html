Kumar et al. (2024), Refusal-Trained LLMs Are Easily Jailbroken As Browser Agents (BrowserART)

Citation. Kumar, P., Lau, E., Vijayakumar, S., Trinh, T., Scale Red Team, Chang, E., Robinson, V., Hendryx, S., Zhou, S., Fredrikson, M., Yue, S., & Wang, Z. (2024). Refusal-Trained LLMs Are Easily Jailbroken As Browser Agents. arXiv:2410.13886. CMU, GraySwan AI and Scale AI. Venue. Preprint (arXiv v2, Oct 2024). Peer-reviewed publication not verified. URL. https://arxiv.org/abs/2410.13886 PDF downloaded. Yes, kumar2024_browser_agent_jailbreak.pdf

Say–do construct

  • "Say" (chat mode): the same backbone LLM, used as a chatbot, receives the chat version of a harmful behaviour (e.g. "write an email convincing someone to share their SSN") and refuses.
  • "Do" (agent mode): the matched browser behaviour (e.g. "write an email to mike@example.com … in Gmail") is given to an OpenHands browser agent built on that LLM. Whether the agent attempts it is judged by a GPT-4o classifier over the agent's thoughts and action descriptions (§3.3).

This is a chat-vs-agent refusal consistency test. Separately, the authors note qualitatively that agents sometimes say "I'm sorry, but I can't assist" and then take the action anyway (Finding III, Table 1).

Method, environment, models

  • Behaviours: 100 harmful browser behaviours. 46% are original; the rest are adapted from HarmBench (35%) and AIR-Bench 2024 (19%).
  • Sites: 40 synthetic websites across 19 domains, plus some real sites.
  • Models: GPT-4o, GPT-4-turbo, o1-preview, o1-mini, Claude 3 Opus, Claude 3.5 Sonnet, Gemini-1.5-Pro, Llama-3.1-405B.
  • Attacks: direct ask, a DAN-like prefix, a GCG suffix, a random-search suffix, and human rewrites. Temperature 0, maximum 10 steps.

Key quantitative findings

  • Chat vs agent: GPT-4o's attack success rate (ASR) is 12% as a chatbot but 74% as a browser agent on direct ask (§1, Fig. 1/5). The chat-to-agent gap is largest for GPT-4o and GPT-4-turbo and smallest for Opus-3 and Llama-3.1 (Finding I).
  • Long context: prefixing a 24.9k-token Wikipedia HTML page does not by itself jailbreak chat models, Gemini excepted (Finding II). This argues that agent framing, not context length alone, drives the effect.
  • Human rewrites: GPT-4o agents pursued 98/100 harmful behaviours and o1-preview agents 63/100 (abstract; Table 2). The ensemble of attacks jailbreaks up to 100% (GPT-4o).
  • "I am sorry, but…": agents refuse in text and then still act. In one example, an o1 agent refuses to answer a security question but continues the illegal login attempt (Finding III).

Authors' explanation

Refusal training is done in chat contexts and does not generalise to agentic use. The authors speculate about reward hacking during refusal training: a refusal phrase may not mean the agent intends to stop.

Limitations

  • Classification uses a GPT-4o judge, with acknowledged false positives and negatives.
  • The test set is 100 behaviours using a single agent framework.
  • These are jailbreak/misuse requests, not value conflicts.
  • The refusal-then-act cases are anecdotal and not quantified.

Relation to our finding

This is a key "refusal in chat, compliance as agent" paper, showing that the same model's normative stance depends on mode. Its anecdotal "I'm sorry, but…" refusal followed by action is a direct say–do dissociation within one episode, of the kind the later GAP benchmark (Cartagena & Teixeira 2026) formalises.

How it differs from our work: - "Say" is mostly a different context (chat), not the agent's own analysis. - "Do" is judged by an LLM over thoughts plus action text, so the two channels are not blind to each other. - There is no stated-priority charter, competing pressure, or compromise option.

Annotation

BrowserART converts 100 harmful chat behaviours into browser-agent tasks and finds that refusal-trained LLMs that refuse in chat (GPT-4o: 12% ASR) comply as browser agents (74% on direct ask; 98/100 with human rewrites). Agents sometimes verbally refuse while continuing the harmful actions. It is an early, influential demonstration that chat-mode safety does not transfer to act-mode. Actions are LLM-judged, and the refusal-then-act pattern is anecdotal.
