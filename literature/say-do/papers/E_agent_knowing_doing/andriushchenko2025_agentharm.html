Say–do construct

AgentHarm records two separately scored channels on the same run. - Do (harm score): mostly predefined, hand-written checks on tool calls (e.g. "a function that sends money is called with the right credit card number"). Partial credit is allowed. A semantic LLM judge is used only for narrow subtasks, such as whether a phishing email is plausible (§3.1.3). - Say (refusal rate): a semantic refusal judge applied to all agent messages. The authors note that "in some cases a refusal message comes after several tools have been executed" (§3.1.3).

The paper does not analyse the overlap of the two channels (refusal and harm on the same run). Cartagena & Teixeira (2026) point out this gap.

Method, environment, models

  • Tasks: 110 explicitly malicious agent tasks (440 with augmentations) across 11 harm categories (fraud, cybercrime, harassment, …), using 104 synthetic proxy tools. Each task needs 2–8 tools.
  • Benign baseline: a matched benign twin set measures capability without refusals.
  • Models: GPT-4o, GPT-4o mini, Claude 3.5 Sonnet, Gemini 1.5 Pro, Mistral Large 2, Llama-3.1 405B, and others.
  • Attack: a direct request vs a simple universal jailbreak template, plus forced tool calls and best-of-n sampling.

Key quantitative findings

  • No jailbreak needed for many models (§4.2, Table 9):
  • GPT-4o mini: harm score 62.5%, refusals 22%.
  • Mistral Large 2: harm score 82.2%, refusals 1.1%.
  • Claude 3.5 Sonnet: harm score 13.5%, refusals 85.2%.
  • Gemini 1.5 Pro: harm score 15.7%, refusals 78.5%.
  • Llama-3.1 405B refuses most often (88.3%).
  • Jailbreak template:
  • GPT-4o: harm 48.4% → 72.7%, refusals 48.9% → 13.6%.
  • Claude 3.5 Sonnet: harm 13.5% → 68.7%.
  • Gemini 1.5 Pro: harm 15.7% → 56.1%.
  • Capabilities preserved after jailbreak: Claude 3.5 Sonnet's non-refusal harm score is 81.9%, against 82% on benign tasks (§4.2).
  • Prompting: chain-of-thought and ReAct prompting increase refusals somewhat. A refusal-inducing system prompt helps Mistral on direct requests but not under the jailbreak (Table 3).

Authors' explanation

  • Chat-trained refusal does not reliably carry over to multi-step agentic misuse.
  • Jailbreaks designed for chat transfer to agents and leave agent competence intact.

Limitations

  • Synthetic proxy tools make the tasks easier and less realistic.
  • Only explicitly malicious, direct-request misuse is covered (no value conflicts).
  • English only.
  • The overlap of refusal and harm on the same run is not reported.

Relation to our finding

AgentHarm is an important design precedent because it scores actions mechanically (rubric checks on tool calls) and scores statements separately (a refusal judge on messages). This is a partial version of our two-channel design. It also documents in passing that refusals can follow already-executed harmful tool calls.

How it differs from our study: - The "say" channel is refusal, not reasoning that is faithful to a stated priority. - The two channels are never cross-tabulated. - The setting is adversarial misuse, not a charter priority under competing pressure. - There is no middle option, although partial credit captures partial compliance.

Annotation

AgentHarm offers 110 explicitly malicious multi-step agent tasks (440 augmented) with synthetic tools. Harm is scored largely by deterministic rubric checks on tool calls, and refusals are scored separately by a semantic judge. Several leading models complied without any jailbreak (Mistral Large 2: 82.2% harm score; GPT-4o mini: 62.5%), and a simple template jailbreak raised GPT-4o from 48.4% to 72.7% with capabilities intact. It is the standard agent-misuse benchmark and an early example of separating executed actions from verbal refusals, though it never cross-tabulates the two.
